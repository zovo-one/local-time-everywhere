Privacy Policy. Local Time Everywhere.

Last updated: 2026-07-21

Summary

Local Time Everywhere runs entirely on your device. It does not collect, transmit, or sell personal data. The extension reads text on the web pages you visit (only on the named hosts listed in the manifest) for the sole purpose of converting zoned times to your local time. All settings and license state stay on this device in Chrome extension storage.

Permissions and why each one is required

  • storage. Save your host list, time format preference, badge toggle, and (if you have Pro) your license state. Nothing else.
  • alarms. A daily tick that checks whether your local time zone crossed a daylight-saving boundary since yesterday. Triggers a refresh of the visible conversions if it did. No data leaves your device in this tick.
  • scripting. Registers the conversion content script on the named hosts below (and on hosts you explicitly add in Options) so the per-host toggle can turn conversions on or off without a page reload.
  • host_permissions (named list). Apply the conversion logic only on the pages where meeting invites actually land. The default ship list is exactly:
    • https://calendar.google.com/calendar/*
    • https://outlook.live.com/calendar/* and https://outlook.office.com/calendar/*
    • https://discord.com/*
    • https://*.slack.com/*
    • https://github.com/* and https://*.github.com/*
    • https://*.start.gg/*, https://liquipedia.net/*
    • https://*.twitch.tv/*, https://twitch.tv/*
    • https://www.youtube.com/*
    The extension never requests <all_urls> and never requests broad access. Hosts you add in Options go into optional_host_permissions and require your explicit grant via the Chrome permission dialog.

What we read

The content script walks visible text nodes on the hosts above, plus any host you explicitly add in Options. The walk finds time+zone pairs (e.g. "3pm EST") and renders an inline conversion to your local time. The matched text and the converted time are processed in memory and never stored or transmitted. We do not read messages, form fields, payment inputs, or anything you type.

What we store

  • storage.sync. Your host list, time format preference, and badge toggle.
  • storage.local. License state (only if you have Pro), the DST epoch, and a rolling 100-event funnel log (kept only on this device, never sent anywhere).

What we transmit

The only network request the extension ever makes is a POST to the Zovo license Edge Function when you enter a license key in Options or in the popup. The request body is your license key and the extension's product ID. No page content, no browsing history, and no profile data is ever sent. If you never enter a license key, the extension never opens a network connection.

The content script that runs on web pages never calls fetch, XMLHttpRequest, or WebSocket. Conversion math uses the browser's built-in Intl.DateTimeFormat API and your device's own time zone, so no page content ever leaves the browser.

Your choices

You can disable the extension on any host from the popup. You can remove any custom host in Options. You can export or delete all local data from the Privacy section of Options. Uninstalling the extension deletes all local data.
